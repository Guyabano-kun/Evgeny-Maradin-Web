The question a reservoir model cannot answer Can the reservoir produce 4 MMbpd? - This is a subsurface question. Can the industry deliver all required infrastructure at the rate the subsurface programme is creating production? - This is an execution system question. These are different questions. A FEL-2 concept study that answers only the first is incomplete. The Study Manager must ask: what becomes limiting when each discipline succeeds - and is there delivery capacity to resolve it in time?
⇅
The constraint migration principle - Removing a bottleneck does not create capacity. It reveals the next constraint. FY2024/25 Khafji: gas pipeline → oil cap → fixed in one quarter. FY2025/26 West Kuwait: acid-gas processing → crude constrained → 6 field experiments launched. Same mechanism. Different geography. The constraint migrates - in location, in layer, in type. A system-level constraint map asks not only "where is the bottleneck?" but "where will it migrate when current investments are complete?" This is the question a production target cannot answer - and a FEL study must.
