# evgeny-maradin.pages.dev

Static site, deployed by Cloudflare Pages from the `web/` folder on every push to `main` (Cloudflare is connected to this GitHub repo directly; there is no deploy workflow here). Other branches get Cloudflare preview deployments.

## How the site is built

Most pages are generated by `tools/build_site.py` (content lives in that script: cases, articles, models, advisory, about).

```
python3 tools/build_site.py web
```

It also writes `web/sitemap.xml` (with `lastmod` from `tools/lastmod.json`, which changes only when a page changes; commit it) and `web/robots.txt`. Search titles/descriptions for key pages live in `SEO` in the script. Social preview image and favicon are made by `python3 tools/make_og.py web` (rerun only if headline or metrics change).

Run it after editing the script, check the result locally (`cd web && python3 -m http.server`), then commit `web/` and push.

Article full texts live in `content/articles/<key>.md` (front matter: title, date, LinkedIn url; body copied verbatim from LinkedIn). For every key in `ARTICLES` that has such a file, the build writes `/insights/<key>/` and article cards link there instead of LinkedIn. In-article images are in `web/img/insights/<key>/NN.webp`; their pixel sizes are in `tools/img_sizes.json` (add an entry when adding an image). To add a new article: add it to `ARTICLES`/`ORDER`, save the cover as `web/img/insights/<key>.webp`, the text as `content/articles/<key>.md`, and rebuild.

## Hand-maintained files (not generated)

- `web/style.css` — all styles
- `web/contact.js` — contact form logic (message / free 30-min call booking)
- `web/functions/api/contact.js` — Cloudflare Pages Function that emails form submissions via Resend (needs `RESEND_API_KEY` secret in Cloudflare)
- `web/models/*/index.html` — interactive models (moved from Netlify), embedded on `/insights/models/*`
- `web/img/insights/*.webp` — article covers (self-hosted copies of LinkedIn covers) and model thumbnails

## Notes

- LinkedIn article cover URLs expire; covers are therefore stored in `web/img/insights/`.
- Old Netlify copies of the models are still referenced from LinkedIn (Kuwait article, comment preview cards) — keep Netlify alive.
